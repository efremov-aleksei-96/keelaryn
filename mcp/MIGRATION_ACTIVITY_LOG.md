# MCP/VPS — журнал фактических операций

Статус: **операционный журнал, не канон проектного состояния**. Единственный план и точный NEXT: [VPS_MIGRATION_PLAN.md](VPS_MIGRATION_PLAN.md). Этот журнал нужен для наблюдения с телефона; в нём фиксируются только проверенные события и запущенные операции, без секретов и личного содержимого. Время — **Ереван (UTC+04:00)**, сверяется с системными часами VPS, а не выводится из времени ответа ChatGPT.

**Как читать:** запись `STARTED` обозначает только запуск. `VERIFIED` — проверенный результат; при отсутствии дальнейших строк нельзя заключить, что ChatGPT продолжает выполняться. Фоновая работа без участия ChatGPT относится только к настроенным службам systemd; их фактические завершения проверяются через системный журнал. GitHub сохраняет историю коммитов этой страницы. Обновление при завершении значимого этапа — не ежесекундный heartbeat.

## Точность и ограничения

- Это **журнал событий**, а не обещание работы часами или 24/7. Интервалы без записей не доказывают ни зависание, ни непрерывную работу.
- Для каждой новой ключевой записи фиксируются время VPS, операция и проверка. Статус `STARTED` не подменяет `VERIFIED`.
- Никаких токенов, содержимого личных документов или чувствительных конфигураций здесь не публиковать.
- Каноническое состояние конкретных проектов — в файлах владельцев на VPS; исторические оригиналы Drive и offsite-копии не являются вторым рабочим каноном.
